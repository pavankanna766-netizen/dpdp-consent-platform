# PrivyStack

> Privacy compliance infrastructure for Indian businesses.

PrivyStack is a modern SaaS platform that helps businesses comply with India's Digital Personal Data Protection (DPDP) Act through consent management, audit-ready records, and automated data deletion workflows.

## 🚀 Vision

Building privacy infrastructure that businesses can integrate in minutes instead of weeks.

The MVP focuses on:

* Secure user authentication
* Consent collection
* Consent history
* Audit-ready consent ledger
* API key management
* Automated data erasure requests
* Developer-friendly SDK

## 🛠 Tech Stack

* Next.js 15
* React 19
* TypeScript
* Tailwind CSS
* Clerk Authentication
* Supabase (Database)
* Vercel (Deployment)
